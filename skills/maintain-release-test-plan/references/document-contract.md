## 固定章节

按以下顺序维护，仓库规范另有要求时可以改标题但不能丢失语义：

1. 当前候选
2. 累计发布范围
3. 相对上一候选版本的增量
4. 重点测试
5. 回归清单
6. 遗留问题
7. 已修问题
8. 风险与回滚
9. 构建历史
10. 发布后验证

“累计发布范围”回答整个核心版本包含什么；“本次增量”只回答当前候选相对上一个候选新增或改变了什么。两者不能互相替代。

## 状态语义

| 状态 | 含义 |
| --- | --- |
| 准备中 | release plan 已生成，尚未完成 version diff |
| 待走查 | 候选构建已准备，等待验证 |
| 走查中 | 有真实执行中的测试记录 |
| 待发布 | 正式版本已准备但外部发布尚未完成 |
| 已发布（冻结） | 正式版本发布完成，普通流程不得再改写 |

状态必须来自实际流程证据，不由 Agent 乐观推断。

## 合并规则

- 以稳定 ID 为主键，以文字相似度为辅助。
- 先读取旧文档，再计算 patch；禁止用新模板覆盖旧文档。
- 保留人工内容，特别是 checkbox、负责人、链接、备注、缺陷编号和测试证据。
- 同一候选版本的构建历史只保留一行。
- 同一 Changeset 在累计范围只保留一个条目，可以更新描述和受影响 package。
- 当前候选的增量在下一个候选到来后仍保留在构建历史中，但“本次增量”章节替换为新候选内容。

## 隐藏标识

使用 HTML comment 提供稳定主键，不影响 Markdown 阅读：

```md
- 支持批量导出订单。 <!-- intent:order-csv-export -->
- [ ] 验证导出权限。 <!-- test:order-export-permission -->
- 登录偶发超时。 <!-- issue:login-timeout -->
```

规则：

- ID 使用小写字母、数字和连字符。
- 优先复用 Changeset 文件名去掉 `.md` 后的值。
- 不因摘要润色而改变 ID。
- 发现重复 ID 时合并信息并保留更完整的人工状态。
